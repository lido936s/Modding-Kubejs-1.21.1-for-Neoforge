# Modding-Kubejs-1.21.1-for-Neoforge

![Minecraft Version](https://shields.io)
![Modloader](https://shields.io)
![API](https://shields.io)

Une collection de scripts d'automatisation et de templates pour **KubeJS** sous **Minecraft 1.21.1 (NeoForge)**. Ce dépôt sert de base modulaire pour interconnecter des mods axés sur la technologie et la survie Skyblock.

---

## 🚀 Contenu du Dépôt

*   **`lychee_pebbles.js`** : Extraction dynamique de cailloux sur la roche (accroupi, avec pioche).
*   **`lychee_leavesdrop.js`** : Récolte de ressources Skyblock sur le feuillage avec un crochet.
*   **`create_mixer_fluid.js`** : Recettes de fluides personnalisées pour le mélangeur de Create.

---

## 🗺️ Guide d'Installation Rapide

### 🛠️ Étape 1 : Préparation (NeoForge 1.21.1)
Attention les mods présent conduit juste aux site de curseforge pour des raisons évidente de compatibilité avec la version de votre neoforge .
Installez les dépendances requises dans votre dossier `mods` :
*   [KubeJS](https://curseforge.com) et [Rhino](https://curseforge.com)
*   [Lychee](https://curseforge.com), [Create](https://curseforge.com), [Ex Deorum](https://curseforge.com) et [Haven Pebbles](https://curseforge.com)

### 📂 Étapes 2 à 4 : Déploiement et Test
1. Lancez le jeu une première fois pour générer le dossier `kubejs`.
2. Placez vos scripts dans `kubejs/server_scripts/`.
3. En jeu, utilisez la commande `/kubejs reload` pour appliquer les changements.
